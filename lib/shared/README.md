# Shared Components
This directory contains reusable UI components and atomic design elements that are used throughout the entire application.

- **buttons/**: Standardized buttons (Primary, Secondary, Outline, Icon).
- **cards/**: Common card layouts for lists and summaries.
- **dialogs/**: Alert dialogs, confirmation popups, and bottom sheets.
- **loading/**: Loading indicators, skeletons, and progress bars.
- **snackbars/**: Success, error, and info notification bars.
- **textfields/**: Styled input fields with validation and iconography.
