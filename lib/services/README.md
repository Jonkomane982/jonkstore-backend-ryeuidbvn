# Services Layer
Handles integration with device hardware, platform APIs, and external services.

- **firebase/**: Firebase initialization and auth service wrappers.
- **storage/**: Cloud (Firebase) and local file storage logic.
- **notification/**: Push and local notification management.
- **camera/**: Image capture, gallery access, and processing.
- **printer/**: ESC/POS and Bluetooth thermal printing logic.
- **barcode/**: Barcode/QR code scanning and generation.
- **sync/**: Logic for synchronizing offline SQLite data with the remote PostgreSQL backend.
