# Authentication Feature
Handles user login, registration, password recovery, and session management.

## Internal Layers:
- **data/**: API client implementations and DTOs.
- **domain/**: Business logic, Entities, and Use Cases.
- **presentation/**: State management logic (e.g. Riverpod Providers).
- **widgets/**: Feature-specific UI components.
- **pages/**: Full screen views.
- **controllers/**: Business logic controllers.
- **repositories/**: Interface definitions for data access.
