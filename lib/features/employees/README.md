# Employees Feature
Handles staff management, roles, permissions, and performance tracking.

## Structure:
- **data/**: Repository implementations and staff data sources.
- **domain/**: Staff entities and business logic.
- **presentation/**: State management for employee data.
- **widgets/**: Employee-specific UI components.
- **pages/**: Employee management screens.
- **controllers/**: UI controllers and providers.
- **repositories/**: Repository interfaces.
