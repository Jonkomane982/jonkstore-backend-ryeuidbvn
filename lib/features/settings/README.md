# Settings Feature
Handles application configuration, user preferences, and system-wide toggles.

## Structure:
- **data/**: Local storage and API settings.
- **domain/**: Setting entities and logic.
- **presentation/**: State management for settings.
- **widgets/**: Setting-specific UI components.
- **pages/**: Settings screens.
- **controllers/**: UI controllers and providers.
- **repositories/**: Repository interfaces.
