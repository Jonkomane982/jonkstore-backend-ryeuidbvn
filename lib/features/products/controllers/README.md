# Products Controllers

This directory houses the state management logic for the Products feature (e.g., Riverpod Notifiers, BLoCs, or GetX Controllers).

### Responsibilities:
- **State Management:** Managing the UI state of product lists, creation forms, and details.
- **Orchestration:** Calling Use Cases (Domain layer) and mapping data to the UI.
- **Input Handling:** Validating and processing user interactions before passing them to the business logic.
