# AI Feature
Handles integration with the Python AI Engine, providing business insights, forecasting, and recommendations.

## Structure:
- **data/**: API implementations for the AI engine.
- **domain/**: AI entities and prediction models.
- **presentation/**: State management for AI features.
- **widgets/**: AI-specific UI components.
- **pages/**: AI assistant and insight screens.
- **controllers/**: UI controllers and providers.
- **repositories/**: Repository interfaces.
