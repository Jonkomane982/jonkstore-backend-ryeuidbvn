# Notifications Feature
Handles in-app notifications, push notification registration, and notification history.

## Structure:
- **data/**: Data sources and repository implementations.
- **domain/**: Notification entities and business logic.
- **presentation/**: State management.
- **widgets/**: UI components like notification tiles.
- **pages/**: Notification center screen.
- **controllers/**: UI controllers and providers.
- **repositories/**: Repository interfaces.
