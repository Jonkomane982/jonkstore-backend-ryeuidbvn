# Analytics Feature
Handles business intelligence, sales trends, and performance metrics.

## Structure:
- **data/**: Repository implementations and analytics data sources.
- **domain/**: Analytics entities and business logic.
- **presentation/**: State management for charts and data views.
- **widgets/**: Analytics-specific UI components (charts, stats).
- **pages/**: Analytics dashboard and detail screens.
- **controllers/**: UI controllers and data providers.
- **repositories/**: Repository interfaces.
