# Purchase Orders Feature
Manages the procurement process, including creating orders for suppliers and tracking incoming stock.

## Subdirectories:
- **data/**: API implementation and DTOs.
- **domain/**: Entities (PurchaseOrder) and business logic.
- **presentation/**: State management logic.
- **widgets/**: Feature-specific UI components.
- **pages/**: Screen layouts.
- **controllers/**: Business logic controllers (Riverpod).
- **repositories/**: Interface definitions.
